# Lakshya Jain — Portfolio Website

A responsive, animated, dark-theme portfolio inspired by the reference website you shared, with original layout and styling.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build step or package installation is required.

## Before publishing — personalize these details
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your real email address (there are two occurrences).
2. Update the GitHub and LinkedIn links in the hero and contact sections with your profiles.
3. Update the education section with your exact college, graduation year, and CGPA if you want them shown.
4. Replace the sample project descriptions with the final project details and add GitHub/demo URLs.
5. If you want a Resume button, add your resume PDF to this folder and link it from the hero section.
6. Review the skills list so it reflects your current level accurately.

## Deploy on GitHub Pages
1. Create a GitHub repository, for example `lakshya-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In repository Settings → Pages, select deploy from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

The contact form uses `mailto:` and opens the visitor's default email application; it does not store messages on a server.
